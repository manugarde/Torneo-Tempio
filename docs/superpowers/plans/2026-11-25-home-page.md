# Pagina Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home di presentazione del torneo su `#/` (logo, periodo+anno, luogo, orari, avviso, menu a colonna, sponsor) e nuova pagina "Eventi giornalieri" gestita dallo staff.

**Architecture:** Nuovi campi nelle impostazioni edizione (con default via `conDefault`), nuova sottoraccolta `edizioni/{anno}/serate` con lo stesso schema store/api delle altre raccolte. `Vista.svelte` mappa `''`→Home, `partite`→Partite, `serate`→Serate. Gestione: sezione "Home" in Impostazioni + scheda "Serate".

**Tech Stack:** Svelte 5 (runes), Vite, Firebase 12 Firestore, Vitest (+ emulatore per `tests/`).

**Spec:** `docs/superpowers/specs/2026-11-25-home-page-design.md`

## Global Constraints

- Default impostazioni: `periodo: 'Giugno'`, `luogo: 'Campetto sintetico, via Campagne 1, Tempio di Ormelle'`, `orari: 'Apertura dalle 19.00'`, `avviso: ''`, `sponsor: ['Powered by Trapatainer']`.
- Testo mostrato del periodo: `` `${periodo} ${anno}` ``; con periodo vuoto solo l'anno.
- Colonna home, in ordine: Risultati e calendario (`/partite`) · Classifica gironi (`/gironi`) · Classifica marcatori (`/giocatori`) · Coppa Chiosco (`/chiosco`) · Tabellone fase finale (`/tabellone`) · Eventi giornalieri (`/serate`). Link sempre via `href()`.
- Barra in basso: Home · Partite · Gironi · Giocatori · Tabellone · Chiosco (6 colonne).
- Nessuna modifica a `firestore.rules`, nessuna nuova dipendenza.
- Testi UI in italiano; stile con i token di `src/app.css`.

## Review Focus

1. Edizione passata (`?ed=2025`): l'avviso non si vede; tutti i link della home conservano `?ed=`. → test in Task 3 (helper `avvisoVisibile`).
2. Periodo vuoto → solo anno, niente spazio iniziale. → test in Task 1 (`testoPeriodo`).
3. Textarea sponsor con righe vuote/spazi → array pulito. → test in Task 1 (`righe`).
4. Data serata `'2027-06-12'` mostrata come 12 giugno anche in fuso UTC-negativo (no `new Date('YYYY-MM-DD')`, che è UTC). → test in Task 1 (`dataLocale`).
5. Rotta sconosciuta (`#/xyz`) → Home, non pagina vuota. → verifica manuale Task 6.
